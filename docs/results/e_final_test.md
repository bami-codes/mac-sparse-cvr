# 연구 E 공식 테스트 결과 (각 질문 1회, 2026-11-19)

- 설계: [docs/DESIGN.md](../DESIGN.md) §18 (개정 1–5). 공식 테스트 파일 `test.parquet` 4,064,648행, SHA-256 `c67dbee7…`.
- 공식 테스트는 1차 실험에서 다른 모델로 한 번 평가한 파일이다. 이번 연구의 선택은 모두 V2(`train-19`)에서 끝냈고 테스트는 고정 뒤 한 번 썼지만, 결과는 "벤치마크 공식 테스트 기준"이며 미열람 자료의 확증이 아니다.
- 평가 코드 `593f03f`(깨끗한 트리). 예행은 V2 값 407개를 1e-9 안에서 재현했다. 예측은 맥 CPU, 학습은 포드 A40 4장. 장치 차이는 V2에서 체크포인트 하나로 확인했다(주 출력 `p_last` 최대 7.86e-7, 보조 출력 포함 최대 4.47e-6, 허용 오차 1e-5).
- 구간: 사용자 군집 부트스트랩 1,000회, 시드 짝(2026·2027·2028), 모델과 보정기는 고정.
- 기록: [records/official_test_q1.json](records/official_test_q1.json), [records/official_test_q2.json](records/official_test_q2.json).

**용어**

- G1(희소 그룹): `train-00`~`17`에서 클릭 3,069건 이상, 양성 123건 미만인 `ad_feat1` 979개. C(비교 집단): 같은 클릭 조건에서 양성 123건 이상인 1,613개.
- (ii) 공통 Platt 보정. (iii) 그룹마다 기울기와 절편을 두고 강도 λ로 (ii) 쪽으로 축소하는 보정. (iii-0) 절편만 그룹별로 축소하는 보정.
- O/E: 관측 양성 수 ÷ 예측 확률의 합. 1보다 크면 과소 예측이다.
- 보정은 모두 V1(`train-18`)에서 맞추고, λ는 V2(`train-19`)에서 골랐다.

|---|---|---|---|---|---|---|---|---|
| BASE | 0.85141 ± 0.0020 | 0.8494 | +0.00201 | 근접 | 0.74188 ± 0.0017 | 0.7424 | −0.00052 | 재현 |

- 판정 기준(사전 고정): |차이| ≤ 0.002 재현, ≤ 0.005 근접. 재현 1개, 근접 3개다. AUC 두 개가 재현 기준을 넘은 양은 BASE 0.0000091, MoAE 0.0000496이다.

## Q2. 논문의 제안 모델(MoAE)에서도 희소 그룹 보정이 도움이 되는가 (G1 979개, `train-17` 시점 모델)

- 사전 판정 기준(차이 < 0, 95% CI 상한 < 0, 시드 3쌍 모두 < 0)을 충족했다. 크기는 공통 보정 뒤 손실 대비 약 0.018%다. 1차 실험(LightGBM, −0.000100)과 비교하면 약 9분의 1이지만, 학습량이 다르고 희소 그룹도 1,083개와 979개 중 838개만 겹치므로 참고 수치다.
- **이 이득은 `train-17`까지 학습한 모델에서 확인한 것이다.** 이 모델에서는 MoAE의 순위 성능이 BASE보다 낮다(아래 "관찰"). 논문처럼 MoAE가 앞서는 `train-19` 모델에서도 같은 이득이 나는지는 이 분할로 알 수 없다. `train-19`까지 학습하면 보정기를 맞출 날짜가 남지 않기 때문이다.
- 효과가 훨씬 큰 것은 공통 보정이다. MoAE의 원시 확률은 G1에서 O/E 1.338로 크게 과소 예측했지만, 과소 예측의 대부분은 전체 수준이었다(전체 O/E 1.247). 공통 보정 (ii)만으로 G1 macro LogLoss가 0.00147 낮아졌고, 그룹별 보정 (iii)은 그 위에 0.000011을 더했다.
- 절편만 축소하는 (iii-0)도 공통 보정보다 나았지만, 기울기까지 축소하는 (iii)보다는 작았다.
- λ는 세 모델 모두 V2에서 (iii) 1000, (iii-0) 100으로 골랐다(주 규칙과 집계 규칙이 같은 값을 골랐다).

### Q2 그룹별 서술 (테스트 뒤에 계산, 판정 없음)

그룹마다 (iii) − (ii) LogLoss를 시드 3개 평균으로 구했다. 979개 그룹의 평균은 위 표의 값과 같다(V2 −0.0000058, 테스트 −0.0000114, 기록값과 1e-12 안에서 일치). 코드 [scripts/q2_per_group.py](../../scripts/q2_per_group.py), 기록 [records/q2_per_group.json](records/q2_per_group.json).

| MoAE, G1 979개 | V2 (λ를 고른 날) | 공식 테스트 |
|---|---|---|
| 개선 / 악화 그룹 | 519 / 460 | 548 / 431 |
| 시드 3개 모두 개선 / 모두 악화 | 379 / 347 | 396 / 325 |
| 그룹별 개선 합 / 악화 합 | 0.0375 / 0.0318 | 0.0439 / 0.0328 |
| 평가일에 양성이 없는 그룹 (그중 개선) | 67 (40) | 68 (41) |

| 학습 양성 수 (G1 기준 < 123) | 그룹 수 | V2 평균 차이 | 테스트 평균 차이 |
|---|---|---|---|
| 0–39 | 231 | −0.0000012 | −0.0000108 |
| 40–79 | 367 | −0.0000085 | −0.0000066 |
| 80–122 | 381 | −0.0000060 | −0.0000165 |

- 순이득은 작은 쪽으로 기운 결과다. 테스트에서 그룹의 44%(431개)는 (iii) 뒤 손실이 오히려 늘었고, 순이득(0.0112)은 개선 합(0.0439)의 약 4분의 1이다. 그룹별 보정은 모든 광고주를 조금씩 낫게 하는 장치가 아니라 그룹마다 양방향으로 움직이고 합이 조금 나은 장치다.
- 학습 양성이 적은 그룹일수록 이득이 크다는 경향은 보이지 않았다. 구간별 순서가 V2와 테스트에서 다르다.
- BASE도 같은 모양이다(테스트 569 / 410, V2 526 / 453).
- 운영에 쓴다면 평균만 보지 말고 그룹별 O/E를 감시해야 한다. 이 표는 그 근거이고, 어떤 그룹이 악화될지 미리 가려내는 규칙은 만들지 않았다.

## 관찰 (사전 계획 밖, 판정 없음)

- **학습 종료 시점에 따라 모델 순위가 뒤집혔다** (같은 공식 테스트 클릭, 전체 AUC, 시드 3개 평균):

  | 마지막 학습 파일 | BASE | MoAE | MoAE − BASE |
  |---|---|---|---|
  | `train-17` (Q2·Q3·Q4의 연구 모델) | 0.8480 | 0.8293 | −0.0187 |
  | `train-19` (Q1의 재현 모델) | 0.8514 | 0.8674 | +0.0159 |

  V2(`train-19`)에서 테스트 전에 기록한 같은 비교(MoAE +0.022, BASE +0.002)와 같은 방향이다. 다만 두 파일만큼 학습 자료와 갱신 횟수가 함께 늘었다. AUC는 순위 성능이지 확률 품질이 아니다. 같은 학습 실행의 인접한 날이라 독립된 반복도 아니고, 파일과 날짜의 대응도 추정이다. 쓸 수 있는 것은 "같은 테스트 클릭에서 학습 종료 파일을 바꾸자 두 모델의 순위 성능이 역전됐다. 재학습 주기를 정하려면 여러 기간에서 확인해야 한다"까지다.

## 쓰지 않을 주장

- 논문 모델을 능가했다. (보정을 비교했을 뿐 새 구조를 제안하지 않았다.)
- 입찰·CPA 효과, 공식 테스트를 미열람 자료의 확증으로 말하는 것.
- AdaCalib 대비 결과 (개정 4에서 사전 비교에서 뺐고, 하지 않았다).
- 작은 맥락 그룹 22개에 대한 결과 (개정 5에서 이번 테스트에서 빼고 후속으로 남겼다).
- 원래 임계값(클릭 500 이상, 양성 20 미만)으로 뽑은 민감도 목록 1,451개 그룹의 결과 (§18.3에서 목록은 고정했지만 성능 민감도 분석은 하지 않았다).
- "확률 품질은 재학습 주기에 달렸다" (학습 종료 시점 비교는 순위 성능에 대한 것이고, 보정 이득은 `train-17` 모델에서만 확인했다).
