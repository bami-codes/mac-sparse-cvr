## 관찰 (사전 계획 밖, 판정 없음)

- **학습 종료 시점**: 같은 공식 테스트 클릭에서, `train-19`까지 학습한 체크포인트(Q1)와 `train-17`까지 학습한 체크포인트(Q2)의 전체 AUC 차이는 MoAE 0.8674 대 0.8293(+0.038), BASE 0.8514 대 0.8480(+0.003)이다. V2(`train-19`)에서 본 같은 비교(MoAE +0.022, BASE +0.002, 테스트 전 기록)와 같은 방향이다. 같은 학습 실행의 인접한 날이라 독립된 반복은 아니다. 파일과 날짜의 대응도 추정이다. 쓸 수 있는 것은 "학습 종료 시점이 MoAE의 순위 성능을 BASE보다 크게 바꿨다. 재학습 주기를 정하려면 여러 기간에서 확인해야 한다"까지다.
