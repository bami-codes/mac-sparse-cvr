# 결과 문서

저장소 첫 화면의 결과는 연구 E(공식 PyMAL 모델)입니다. 그 앞의 실험들은 같은 MAC 자료에서 LightGBM과 작은 신경망으로 했고, 연구 E의 질문과 방법이 여기서 나왔습니다. 설계와 판정 기준은 [DESIGN.md](../DESIGN.md)의 해당 절에 있고, 명령은 [reproduce.md](../reproduce.md)에 있습니다.

| 실험 | 질문 | 결과 | 문서 |
|---|---|---|---|
| 1차 실험 (§10) | LightGBM 위에서 희소 그룹의 그룹별 축소 보정이 공통 보정보다 나은가 | 희소 그룹 LogLoss −0.000100 [−0.000154, −0.000049], 개선 확인 (공식 테스트) | [V2 선택](dev_v2_selection.md), [테스트](final_test.md), [지연](latency.md) |
| 2차 실험 (§13) | 보조 귀속 레이블(`mta`) 예측과 그룹 전환율을 입력으로 넣으면 나아지는가 | −0.000145 [−0.000292, +0.000010], 확인되지 않음 (`train-12`) | [V2 선택](p2_dev_v2_selection.md), [테스트](p2_final_test.md), [지연](p2_latency.md) |
| 연구 A (§15) | 보정 자료의 양에 따라 그룹별 보정의 이득이 어떻게 변하는가 | 개발 자료만 사용, 판정 없음 | [표](calibration_data_study.md) |
| 연구 B (§15) | 2차 실험의 이득이 귀속 정보 때문인가, 같은 레이블의 대조로 확인 | 개발 자료만 사용, 판정 없음 | [표](aux_label_control.md) |
| 연구 C (§16) | 작은 광고 맥락 그룹에서 도메인별 구조(공유·헤드·STAR)가 도메인 절편보다 나은가 | +0.000027 [−0.000050, +0.000107], 확인되지 않음 (`train-13`·`14`) | [V2 선택](c_dev_v2_selection.md), [예행](c_dryrun_v2.md), [테스트](c_final_test.md), [지연](c_latency.md) |
| 연구 D (§17) | 절편만 축소하는 보정과, 보정 강도를 고르는 지표의 영향 | 이미 연 자료의 백테스트, 확증 아님 | [표](study_d.md) |
| 연구 E (§18) | 공식 BASE·MoAE의 재현, 희소 그룹 보정, 서빙 지연 | 저장소 첫 화면 | [공식 테스트](e_final_test.md), [서빙](e_serving.md), [기록](records/README.md) |

- 1차·2차 실험과 연구 A–D의 문서는 실행 코드가 만든 표라 영어로 되어 있습니다.
- 각 실험의 테스트는 질문마다 한 번만 실행했습니다. MAC의 학습 파일 20개와 공식 테스트는 모두 어느 실험에서든 이미 열었기 때문에, 새 확증 실험에 쓸 미열람 자료는 남아 있지 않습니다([reproduce.md](../reproduce.md) §4).
